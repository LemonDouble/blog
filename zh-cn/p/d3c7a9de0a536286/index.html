AWS SAA 当日报名考试合格回顾

2024.08.04 • 3 min read

注：作者居住在韩国，部分内容包含韩国特有的背景。

AWS 提供实用的认证资格。(Link )

我一直跟自己说"以后再考、以后再考"，但再这样下去恐怕一辈子也考不到，今天正好没安排，干脆当天报名直接参加了在线考试。

关于这个认证是什么、考下来有什么好处、怎么备考之类的文章已经非常多了，这部分就交给别的博客吧。我这里只按 2024 年的情况整理一下报名流程、注意事项和考试感受。

1. 报名

进入 AWS 认证 链接，点击"预约考试时间"即可预约。

我选了 Online with OnVUE，参加了在线考试。 考试准备时需要 摄像头，如果你还没有，请提前准备好！

考试可以用韩语报名。即使用韩语报名，考试中如果觉得翻译有问题，也可以查看英文原文。

另外还有一个小提示：花点时间找一下，找到一张 AWS 折扣券的概率挺高的，建议先找一下再报名。

我用的是 Reddit 上的折扣券链接，如果时间宽裕的话，去 AWS Korea User Group 1 的 Slack 等地方问问折扣信息也是不错的选择。

2. 准备

下载程序后按指引操作，搭建考试环境本身一般没什么大问题。

不过，有些后台进程会引起问题。我自己就遇到过，明明按要求关掉了所有前台进程，后台在跑的 Chrome 远程桌面服务还是差点害我没法开考。

3. 考试

考试的流程是

  1. 考试开始前 30 分钟先进入 Check in
  2. 拍人脸照、身份证照片、考试场地（周围环境）照片
  3. 通过摄像头与监考官连线，伸出手让对方确认没戴手表、展示全身、用摄像头确认桌面和周围没有任何东西
  4. 然后开始考试

按这样的顺序进行。

题目整体难度一般。如果有不太确定的题：

  1. 如果有多个类似的服务，就选最近推出的那个（比如 CLB 和 ALB 之间，ALB 大概率是答案，对吧？）
  2. 选 AWS 正在主推的关键词，比如 Serverless

差不多就是这些蒙题小技巧（……）。

4. 结果通知

听说以前考试一结束就出结果，但我这次不是这样。

我是当天 11 点左右报名当天 13:15 的考试，12:45 开始 Check in，2 点左右结束考试出来。

考试结果在 19:15 左右才到，大概处理需要 5～6 小时。

合格后会收到这样的邮件。

我已经很久没用 AWS 了，所以很多题都是凭记忆边回忆边做的。

之前因为价格不便宜一直没敢考，但想着这样下去一辈子也考不到，就抱着"挂了就挂了"的心态去考，结果还不错～

接下来想试试 Developer 认证，不过具体什么时候考还在考虑中。那就先这样～
